# dashboard

The Tracium trace viewer — a React single-page app. It renders the overview
(cost/latency/error KPIs and time series), the trace explorer and inspector, and
per-agent, usage, and settings views.

It is a **pure client of [`api`](../api)**. It holds no data of
its own, talks to no database, and knows only the `/v1` REST surface — no direct
ClickHouse access, ever. Every request it makes is bounded by a time range and a
page size; an unbounded fetch is exactly what turns a healthy backend slow, so
that discipline is a rule, not a preference. The
trace explorer is wired to the live API; some of the other views still render
local fixtures (`data.ts`) pending their endpoints.

## Stack

React 18 + TypeScript, built with Vite. Server state is
[TanStack Query](https://tanstack.com/query) (caching, polling, refetch);
routing is React Router; tests run on Vitest + Testing Library. No global state
library — server data lives in query caches, UI state stays local to components.

## Layout

Code is organised by feature module, not by file type. Each module under
`src/modules/` owns its own components, hooks, and API calls; anything shared
across modules lives in `src/common/`.

```
src/
  modules/
    overview/         KPI cards + cost/latency/error series
    trace-explorer/   the trace list (paginated, windowed) + Gantt trace detail
    trace-inspector/  deep span inspector: attributes, tool calls, I/O
    agents/  usage/    per-agent and per-tenant breakdowns
    auth/  api-keys/  settings/  shell/   account + app chrome
  common/             api client, shared hooks/components, providers
  types/              types generated from spec (do not hand-edit)
```

`src/types/` is generated by `spec`'s codegen — regenerate it there, never
edit it by hand.

## Run

```bash
npm install
npm run dev        # Vite dev server on :5173, calls the API at VITE_API_URL
npm run build      # tsc typecheck, then production bundle → dist/
npm test           # vitest
```

The API base URL comes from `VITE_API_URL` (defaults to `http://localhost:8090`).
Set it at build time for a real deployment:

```bash
VITE_API_URL=https://api.tracium.example.com npm run build
```

The [Dockerfile](Dockerfile) builds the bundle and serves it with nginx on port
3000 with SPA fallback (see [nginx.conf](nginx.conf)); the compose stack passes
`VITE_API_URL` as a build arg.
