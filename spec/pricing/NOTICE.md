# Pricing data attribution

`pricing.json` is generated by `refresh-pricing.sh` from the model pricing table
maintained by the LiteLLM project:

- Source: https://github.com/BerriAI/litellm
  (`litellm/model_prices_and_context_window_backup.json`)
- License: MIT

Only the per-token cost fields Tracium prices on (input/output cost, prompt-cache
read/write cost, and long-context tier overrides) are projected into
`pricing.json`; all other LiteLLM metadata is dropped. The `source` field in the
generated file records the exact upstream commit the snapshot was taken from.
